# AI 식단 관리 HealthMate - 기술 명세서

## 1. 프로젝트 개요

**HealthMate**는 사용자가 음식 사진 한 장으로 식단을 손쉽게 기록하고, AI를 통해 칼로리 및 영양소를 분석받을 수 있는 모바일 웹 애플리케이션입니다. 단순 기록을 넘어, AI가 개인의 데이터를 기반으로 맞춤형 건강 솔루션(식단 계획, 운동 추천, 식습관 분석)을 제안하여 사용자가 건강한 라이프스타일을 형성하고 유지하도록 돕는 것을 목표로 합니다.

## 2. 핵심 기능 상세

### F1: AI 음식 사진 분석 및 기록
-   **사진으로 기록**: 사용자는 카메라로 직접 사진을 찍거나 갤러리에서 이미지를 업로드하여 식단을 기록할 수 있습니다.
-   **Gemini Vision 분석**: 업로드된 이미지는 Google Gemini API를 통해 분석되며, 사진 속 음식 각각의 이름, 1인분 기준 양(g), 칼로리, 주요 영양소(탄수화물, 단백질, 지방)를 JSON 형태로 반환받습니다.
-   **다중 음식 인식**: 한 사진에 여러 음식이 있어도 각각을 개별 항목으로 인식하고 분석합니다.
-   **결과 수정 및 추가**: AI 분석 결과를 사용자가 직접 수정하거나 목록에서 제거할 수 있으며, 식사 시간(아침, 점심, 저녁 등)을 지정하여 최종 기록합니다.

### F2: 수동 기록 및 텍스트 기반 분석
-   **텍스트로 기록**: 음식 이름을 직접 입력하여 식단을 기록할 수 있습니다.
-   **Gemini 텍스트 분석**: 입력된 텍스트는 Gemini API로 전송되어 해당 음식의 일반적인 영양 정보를 분석하고 반환받습니다.

### F3: 대시보드 및 일일 통계
-   **실시간 칼로리 추적**: 오늘의 총 섭취 칼로리와 목표 칼로리를 시각적으로 비교하여 보여줍니다.
-   **영양소 비율**: 섭취한 탄수화물, 단백질, 지방의 비율을 원형 차트로 시각화합니다.
-   **수분 섭취 기록**: 하루 물 섭취량을 손쉽게 기록하고 목표 달성률을 확인할 수 있습니다.
-   **AI 제안 카드**: 일일 섭취량 분석을 바탕으로 AI가 동적으로 운동, 단백질 보충 등 맞춤형 제안을 생성합니다.

### F4: 분석 및 계획 (Analysis & Planning)
-   **장기 데이터 분석**: 최근 7일 또는 30일간의 데이터를 기반으로 식습관을 분석합니다.
-   **칼로리 트렌드**: 일별 칼로리 섭취량 변화를 꺾은선 그래프로 시각화합니다.
-   **AI 식습관 분석**: AI가 식단 기록을 바탕으로 칭찬할 점과 개선점을 요약하여 피드백을 제공합니다.
-   **식습관 패턴 분석**: 야식 빈도, 주말/평일 섭취 칼로리 차이 등 라이프스타일 패턴을 분석하고 AI가 심층 리포트를 제공합니다.
-   **영양 균형**: 주요 영양소의 섭취 비율을 권장 비율과 비교하여 레이더 차트로 보여줍니다.
-   **식사 시간 패턴**: 요일 및 시간대별 평균 섭취 칼로리를 히트맵으로 시각화합니다.

### F5: AI 기반 개인화 기능
-   **AI 식단 플래너**: 사용자의 프로필(목표 칼로리 등)과 선호도(예: 고단백, 채식)를 입력하면 AI가 하루 맞춤 식단(아침, 점심, 저녁)을 생성합니다.
-   **냉장고 파먹기 AI 레시피**: 사용자가 현재 가지고 있는 재료를 입력하면 AI가 만들 수 있는 건강 레시피를 제안합니다.
-   **AI 챌린지**: 식단 기록을 분석하여 사용자가 도전할 만한 재미있는 단기 목표를 AI가 생성하고 제안합니다.
-   **AI 운동 계획**: 주간 섭취 칼로리와 사용자 프로필을 바탕으로 AI가 맞춤형 주간 운동 계획을 제안합니다.

### F6: AI 채팅
-   **대화형 AI 영양사**: 사용자의 식단 기록을 기반으로 학습된 AI와 자유롭게 대화하며 식단, 운동 등에 대한 질문을 하고 개인화된 답변을 받을 수 있습니다.

### F7: 소셜 및 게이미피케이션
-   **그룹**: 사용자는 그룹을 생성하거나 참여하여 친구들과 함께 목표를 공유하고 경쟁할 수 있습니다.
-   **그룹 피드**: 그룹 내에서 식단 기록, 챌린지 달성 등의 활동이 실시간 피드로 공유됩니다.
-   **챌린지 및 업적**: '아침 식사 챙기기', '단백질 목표 달성' 등 장기적인 챌린지를 제공하며, 특정 조건을 달성하면 배지를 획득하는 업적 시스템이 있습니다.

### F8: 프로필 및 설정
-   **개인 프로필**: 성별, 나이, 키, 체중, 활동량 등 신체 정보를 설정하여 더 정확한 칼로리 목표를 계산합니다.
-   **설정**: 라이트/다크 모드 등 앱 테마를 설정하고, 모든 기록 데이터를 관리(삭제)할 수 있습니다.

## 3. 기술 스택 및 아키텍처

-   **Frontend**: `React`, `TypeScript`, `Tailwind CSS`
-   **AI**: `Google Gemini API (@google/genai)` (gemini-2.5-flash 모델)
-   **State Management**: React Hooks (`useState`, `useCallback`, `useMemo` 등)
-   **Charting**: `Recharts`
-   **Icons**: `Lucide React`

### 프로젝트 구조
```
/
├── components/       # 재사용 가능한 UI 컴포넌트
│   ├── charts/       # 차트 관련 컴포넌트
│   └── ...
├── pages/            # 각 페이지 컴포넌트
│   └── ...
├── services/         # 외부 API 호출 및 비즈니스 로직
├── types/            # TypeScript 타입 정의
├── utils/            # 유틸리티 함수
├── App.tsx           # 메인 애플리케이션 컴포넌트 (상태 및 라우팅 관리)
├── index.tsx         # React 앱 진입점
└── index.html        # HTML 템플릿
```

## 4. 화면 구성

-   **`HomePage`**: 메인 대시보드. 일일 섭취 칼로리, 영양소, 식단 기록, AI 제안 등을 표시.
-   **`AnalysisPage`**: 데이터 분석 페이지. 장기 트렌드, AI 분석, 식단 플래너, 챌린지 기능 등을 탭으로 제공.
-   **`ChatPage`**: AI 영양사와 대화할 수 있는 채팅 인터페이스.
-   **`GroupsPage`**: 참여 중인 그룹 목록을 보여주고, 새 그룹을 생성할 수 있음.
-   **`GroupDetailPage`**: 특정 그룹의 멤버, 챌린지, 실시간 피드를 확인.
-   **`ProfilePage`**: 사용자 정보, 친구 목록, 획득한 업적 등을 확인.
-   **`SettingsPage`**: 앱 테마, 알림, 데이터 관리 등 설정 기능.
-   **Modals**:
    -   `AnalysisModal`: 사진 분석 결과 표시 및 수정.
    -   `ManualAddModal`: 수동 식단 추가.
    -   `ProfileEditModal`: 프로필 정보 수정.
    -   `CameraModal`: 사진 촬영 인터페이스.
    -   `...` 등 다양한 인터랙션을 위한 모달.
